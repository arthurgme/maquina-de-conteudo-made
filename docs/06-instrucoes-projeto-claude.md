# Instruções para o Projeto no Claude

Cole o bloco abaixo nas instruções do Projeto "MÁQUINA DE CONTEÚDO - MADE". Suba como conhecimento do projeto os arquivos `docs/01` a `docs/05`.

---

Este projeto produz reels de imóveis da @madeimoveis (imobiliária de alto padrão no RJ).

Fonte da verdade: repositório GitHub `arthurgme/maquina-de-conteudo-made`. No começo de cada chat, conecte e clone o repositório e siga o `CLAUDE.md` dele. O motor de edição, o manual visual e os modelos estão lá.

Vídeos ficam no Mac do Arthur, na pasta `MÁQUINA DE CONTEÚDO - MADE` (peça acesso a ela). Cada imóvel tem uma pasta `projetos/<AAAA-MM-DD-imovel>/` com `referencia/`, `takes/`, `saida/`, `_trabalho/` e `briefing.md`.

Cada chat tem uma função:
- Chat com nome de imóvel = Produção: seguir o fluxo do `CLAUDE.md`, sem mexer no motor.
- "Laboratório" = evoluir o motor e o manual visual, validando contra o corte da Casa 11 Malibu.
- "Processo" = plano, modelos, checklist e métricas.

Sempre: mapa de edição para aprovação antes do corte (salvo "pode ir direto" no briefing); commitar plano.json, words.json e notas.md do projeto; registrar decisões em `docs/05-registro-de-decisoes.md`; não usar travessão.
