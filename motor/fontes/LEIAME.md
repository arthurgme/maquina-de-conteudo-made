# Fontes

- **Inter SemiBold** e **Inter Display Black**: Rasmus Andersson, SIL Open Font License 1.1 (rsms.me/inter)
- **Playfair Display Italic**: Claus Eggers Sørensen, SIL Open Font License 1.1 (Google Fonts, via pacote npm @expo-google-fonts/playfair-display)

Uso: legenda em Inter SemiBold, palavras de ênfase em Playfair Display Italic, selos em Inter Display Black.
O motor passa esta pasta ao libass (`fontsdir`), então não é preciso instalar as fontes no sistema.
